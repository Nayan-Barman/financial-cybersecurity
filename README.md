
# Financial Cybersecurity Website
A responsive educational website that provides practical information and
guidance about financial cybersecurity.

## Project Overview
This project was developed as a four-task web development exercise:

1. Build a local website using HTML and CSS.
2. Add researched financial cybersecurity information.
3. Stylize the website according to the provided Commonwealth Bank
   style guidelines.
4. Develop a proposal for securely hosting the website.

## Features
- Responsive design
- Financial cybersecurity education
- Common cybersecurity threats
- 10 practical security tips
- Security checklist
- Responsive navigation
- Brand-inspired visual design
- Accessible high-contrast color scheme
- Secure web-hosting recommendations

## Technologies
- HTML5
- CSS3
- Responsive Web Design
- Git
- GitHub
